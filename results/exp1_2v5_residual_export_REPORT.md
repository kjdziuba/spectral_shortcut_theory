## 1. The model, and which runner instantiates it

`prop:verified_instance` (`paper/sections/supplement.tex` L252) is the **linear
per-pixel spectral map $f_\theta$ followed by a two-layer ReLU head $g_\phi$ at
Kaiming Gaussian initialization with a fixed bias variance $\sigma_b>0$**. In this
repository that is

```python
CompositionModel(SpectralReduction(S=64, K=16),                  # f_theta, linear, no bias
                 SpatialMLP(K=16, n_classes=2, width=D,          # g_phi, K -> D -> 2, ReLU
                            init_mode='theorem', sigma_b=0.5))   # N(0, 2/fan_in), bias N(0, 0.5^2)
```

**Which runner instantiates it:** `code/experiments/exp1_1v3.py` with `arch='mlp'`
and `--init_mode theorem` — that is the only place the verified instance appears.
It measures GGN block eigenvalues **at initialization only and never trains**.

**`exp1_2v4.py` does not instantiate it.** Its spatial heads are `SpatialCNN` and
`SpatialViT` (`ARCH_WIDTHS = {'cnn': [...], 'vit': [...]}`); there is no MLP arm.
This runner therefore combines exp1_1v3's *model* with exp1_2v4's *training
protocol*, importing both rather than copying either:

| item | value | source |
|---|---|---|
| data | `make_problem`, S=64, H=W=16, C=2, alpha=beta=1.0, noise=0.10, 512 train / 128 test | `exp1_2v4` constants |
| optimizer | Adam, lr 1e-3, batch 32, 150 epochs = 2400 steps | `exp1_2v4` constants |
| loss | per-pixel softmax CE, `reduction='mean'` | `exp1_2v4.per_pixel_ce` |
| widths | D in [128, 512, 2048] | as requested |
| seeds | [42, 43, 44] | as requested |
| arms | `joint`, `frozen` | exp1_2v4 has a frozen arm, so both were run |
| head init | `init_mode='theorem'`, sigma_b=0.5 | required by `prop:verified_instance` (PyTorch's default bias variance Theta(1/fan_in) does not satisfy sigma_b>0 fixed) |

**Frozen-arm convention.** `exp1_2v4` freezes with `requires_grad=False`, which makes
the EGR numerator zero *by construction*. Here the spectral parameters keep
`requires_grad=True` but are excluded from the optimizer's parameter list. The
trajectory is identical to exp1_2v4's frozen arm (Adam only steps what it is given);
the logged theta gradient is the **counterfactual** signal a frozen encoder would have
received, which is what makes quantity (vi) meaningful on that arm.

## 2. Probe batch, normalization, validation

**N = 256 supervised sites, C = 2 classes, so the logit space is
R^(NC) with NC = 512.** The model is a per-pixel segmenter, so the
residual and both kernels live on *sites* (pixels), not on images: the probe is
256 pixels drawn once, with a fixed RNG seed, from the first
16 training images of that run's dataset, and held
fixed for the whole trajectory. Non-probe pixels are set to `ignore_index=255`, so
`hessian/ggn.py` — which counts valid pixels itself — sees exactly the same N and the
same site set.

Normalization follows `code/hessian/ggn.py` exactly: with `z = N^{-1/2} stack(yhat)`
and averaged CE,

```
r      = N^{-1/2} (softmax(z) - onehot(y))       in R^{NC}
J_b    = N^{-1/2} d(yhat)/d(b)                   so grad_b L = J_b^T r  exactly
K_b    = J_b J_b^T                               (NC x NC, dense, float64)
G_bb   = J_b^T H J_b,   H = blkdiag(diag(p_n) - p_n p_n^T)
```

Three validation identities are recomputed at **every** one of the
198 measurements:

| identity | max relative error over all rows |
|---|---|
| `a_eff * \|r\|^2 == \|grad_theta L\|^2` (autograd) | 1.30e-15 |
| `kappa_eff * \|r\|^2 == \|grad_phi L\|^2` (autograd) | 1.62e-14 |
| `lam_max(H^(1/2) K_phi H^(1/2)) == lam_max(G_phiphi)` (`hessian/ggn.py` power iteration) | 2.47e-15 |

All at float64 round-off. The kernels are therefore the same objects the packet's GGN
machinery measures, in the packet's own normalization.

**Definitions used below.**

| symbol | definition |
|---|---|
| `a_eff` | r^T K_theta r / \|r\|^2 — the *actual* spectral Rayleigh quotient on the visited residual |
| `kappa_eff` | r^T K_phi r / \|r\|^2 — the *actual* spatial coercivity on the visited residual |
| `f_k` | fraction of \|r\|^2 inside the top-k eigenspace of K_phi (k = 1, 5, 20, 100) |
| `sv_k` | fraction of \|r\|^2 inside the top-k left singular subspace of J_theta (k = 1, 5, 20) |
| `share` | r^T K_theta r / (r^T K_theta r + r^T K_phi r) = a_eff/(a_eff+kappa_eff) — the (A1) bound of `math_02.md` §2.1, and the instantaneous gradient-flow share. **These coincide by construction**; the CSV carries both columns (`share_inst`, `share_A1_bound`) and they agree to the last digit. |
| `proxy_max` | lam_max(K_theta) / (lam_max(K_theta) + lam_max(K_phi)) — the top-eigenvalue proxy |
| `proxy_min` | lam_max(K_theta) / (lam_max(K_theta) + lam_min(K_phi)) — the worst-case-coercivity proxy |
| `cum` | cumulative discrete share sum_t\|g_theta\|^2 / sum_t(\|g_theta\|^2+\|g_phi\|^2) from the per-step EGR log, up to that checkpoint |

**Reference value for the subspace fractions.** A residual with no preferred direction
in R^512 puts k/NC of its mass in any k-dimensional subspace: `f_1` = 0.0020, `f_5` = 0.0098, `f_20` = 0.0391, `f_100` = 0.1953. Numbers below that line mean the residual is *anti*-aligned with the fast
part of K_phi, not merely unaligned.

## 5. CE Hessian weighting (H^(1/2) K H^(1/2))

## 8. Plain statement of what the numbers say

On this instance `K_phi` is extremely ill-conditioned on the probe logit space:
`lam_max/lam_min` has median **1.28e+06** on the joint arm (range 2.42e+05 to 1.06e+07), and on the larger NC = 2048 probe `lam_min(K_phi)` reaches float64 zero (min -2.6e-15), so **Theorem 1.3's hypothesis `K_phi >= kappa I` taken on the FULL output space is available only with `kappa = lam_min`, which is five to seven orders of magnitude below `lam_max` and yields nothing.** The visited residual does not lie in that near-null part: `kappa_eff` is between **225x** and a median **5.0e+03x** larger than `lam_min` at every checkpoint measured. Nor does it lie in the coercive top of the spectrum: `kappa_eff` is a median **0.0025** of `lam_max` (range 2.5e-04 to 0.537); the top eigendirection of `K_phi` carries a median **8.6e-05** of ||r||^2 after step 75 (down from a median 0.0233 at t = 0); the top-20 eigenspace carries a median **0.0298** (down from 0.446); and the top-100 of 512 carries a median **0.1612**, *below* the 0.1953 an isotropic residual would put there. The spectral side collapses the same way: the top left singular direction of `J_theta` carries a median **6.2e-04** of ||r||^2 after step 75, down from 0.1513 at t = 0, and on the NC = 2048 probe, where `range(J_theta)` is a proper 1024-dimensional subspace, the residual's mass inside it is 0.489-0.833 (median 0.621) against the isotropic 0.500. So a Theorem 1.3 hypothesis with V = the whole output space is unavailable on this instance, and a usable `kappa` exists only as the measured `kappa_eff` on the residual actually visited. Measured against that share, the top-eigenvalue proxy `lam_max(K_theta)/(lam_max(K_theta)+lam_max(K_phi))` **under**states theta's share in **85%** of joint rows, by a median factor **2.72** and up to **11.6x**, and **over**states it by up to **11.1x** in the remaining 15% — it errs in both directions and is a bound in neither (2.65 median, 0.049-10.8 range on the frozen arm). The worst-case-coercivity proxy `lam_max(K_theta)/(lam_max(K_theta)+lam_min(K_phi))` is 0.9998-1.0000 at every one of the 198 rows, i.e. entirely vacuous. Every figure above is a checkpoint diagnostic: §4 gives all 11 checkpoints for all 18 runs precisely so that no single overlap is read as evidence of persistence.
