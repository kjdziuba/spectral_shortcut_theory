**B5 — Blocker for the numerical theorem-bound claim: the current `thm2_bound` is a heuristic proxy, not an instantiated bound.** Location: §8.5; [analyze_e3c.py](/home/u37314kd/Projects/spectral_shortcut_theory/code/experiments/analyze_e3c.py:35).

The code fits an envelope to a centered rolling median of mini-batch residuals, takes C from the first ten smoothed steps, computes μ against an integer step index, uses the 99th percentile of `||gradient||/||residual||`, and inserts a terminal averaged residual into the fitting-time expression. It compares that quantity with final displacement under AdamW or clipped momentum SGD. This creates several distinct gaps:

- A percentile is not a supremum. The maximum realized gain can replace an operator-norm bound along the same trajectory for the velocity inequality; the 99th percentile cannot do so without an explicit tail contribution.
- An envelope for a smoothed mini-batch statistic is not an envelope for the full-data residual along the flow, and the warm-up constraints are not all checked.
- Time units matter. Even for constant-step plain gradient descent, the elementary displacement bound is `||θ_K−θ₀|| ≤ Σ_k η ||∇_θ L_k||`. If `t_flow = ηk`, then `μ_flow = μ_step/η`. Substituting μ_step directly into a flow expression without the corresponding factor of η changes its scale by 1/η. The code does not perform that conversion. Momentum, clipping, and Adam require their own treatment; multiplying by the nominal learning rate does not repair the existing experiment.
- First hitting time, terminal time, and a smoothed terminal residual are different quantities.

Consequently I do **not** accept “the real-data theorem bound is vacuous by 10⁴–2×10⁵” as a verified quantitative result. The proxy is huge; that is what is established. It may remain uninformative after a valid construction, but the advertised magnitude must be recomputed or removed. This correction narrows a negative claim about the theorem; it does not make the theory empirically successful.

Action: export a unit-annotated audit distinguishing raw/full-batch residual, sampled gain, operator norm, applied update, time convention, and stopping time. In the main paper, use “we do not obtain a useful certified bound for the production training regime.” For the synthetic illustration, use deterministic full-batch data, step-size refinement, an unsmoothed envelope checked over the stated horizon, and an explicit accounting for numerical approximation. A sampled trajectory is evidence, not an automatic continuous-time certificate.

**M1 — Major: the optimization and representation explanations still have inexpensive alternatives.** Locations: §8.4; parameter grouping and clipping in `exp1_7_train.py`.

First, freezing also freezes the post-projection BN affine parameters in frozen-random while joint-linear trains them in φ. Parameter count is not a defense: normalization parameters can have large functional effects. Second, clipping uses all optimizer parameters. At the same initial gradients, joint clipping depends on both θ and φ norms, while frozen clipping excludes θ. Thus freezing can immediately change the applied φ update even before any feature drift. This effect is particularly transparent for SGD; Adam’s history makes the interpretation more complicated. Third, validation collapse may partly involve BN running-statistic mismatch under changing features and small core batches. That is a testable alternative, not a diagnosed bug.

Action: make the BN affine treatment identical in the matched causal comparison; log clipping coefficients and actual per-block update norms; evaluate saved final checkpoints before and after training-only BN recalibration on disposable copies. Recalibration must use training data only, with fixed weights, and retain the original evaluation alongside it. If it restores most of the lost validation performance, the “harmful feature drift” interpretation changes substantially. Joint-MLP lacks the same spectral BN, but the spatial decoder still uses BN, so the alternative cannot be dismissed solely from that arm.
